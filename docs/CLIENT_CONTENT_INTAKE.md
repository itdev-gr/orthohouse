You do **not** need to send us any of the below — these are read live from your Shopify store and refresh automatically. Edit them in Shopify Admin whenever you like and the website updates.

**Per product:** title, description (plain + rich HTML), tags, price, sale "compare-at" price, currency, featured image, gallery (up to 10), in-stock / out-of-stock status, SKU (product code), variants and per-variant prices/availability, collection membership.

**Per collection:** title, description, handle (URL slug), Shopify collection image (currently unused on the site — see "Optional" section at the bottom if you'd like us to switch banners to be Shopify-driven).
